📘 Overview

This is the production‑grade Fun‑Sphere Fantasy Engine repository.  
It contains the runtime, UI, glyph atlas, XR surfaces, and engine‑level scaffolding that will eventually power the playable Fun‑Sphere experience.

This repo is under construction 🏗.  
The engine is being built step‑by‑step as the mathematical foundations (Unified Math Spine, CSO geometry, Triad operators, holonomy‑runtime behavior) stabilize in the test and membrane repos.

This repo does not contain:

- Tile Explainers  
- Unified Math Spine pedagogy  
- altitude‑layer narrative physics  
- operator derivations  
- preprint fragments  
- Lean formalization  
- math R&D  

Those live in:

- fun-sphere-fantasy-engine-test (pedagogy + math R&D)  
- Consolidation-Horizon (neutral membrane + integration docs)  
- Constellation-Manifold-Toolkit (pure math + operators)

This repo is the runtime/UI engine, not the math.
